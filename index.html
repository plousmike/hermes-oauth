Hermes Agent

Personal automation software, run by one person on one machine.

What Hermes Agent is

Personal automation software, built on the open source Hermes Agent framework from Nous Research. It runs on one Linux machine that belongs to the account holder, inside his own home network.

There is one user: the account holder. The software is not sold, not distributed, and not offered to anyone else. It is not a company or a product. It is a tool one person uses to get his own work done.

What it does with Google

When the account holder asks it to, the agent works on his own Google account. It can:

  • Read and write files in his own Google Drive.
  • Read, change and send mail from his own Gmail account.
  • Read and write his own Google Calendar.
  • Read and edit his own Google Docs and Google Sheets.
  • Read his own Google Contacts.

It asks Google for access to those services only so it can do tasks he sets: filing notes, putting documents together, scheduling things, drafting and sending mail he has asked for, and keeping records. It uses nothing else, and it acts for no one else.

Where the data stays

On his own machine and in his own Google account. There is no server behind this software. No one else receives the data.
