Hermes Agent

Personal automation software, run by one person on one machine.

Privacy policy

Last updated: 26 October 2026

This policy covers the Hermes Agent app and the Google account it is connected to. The app has one user: the account holder. Every statement below is about his own data and no one else's.

What data the app can access

The app asks Google for access to these services, and only these:

  • Google Drive. Read and write access to the files in the account holder's own Drive.
  • Gmail. Read, change and send from the account holder's own mailbox.
  • Google Calendar. Read and write the account holder's own calendars.
  • Google Docs and Google Sheets. Read and edit the account holder's own documents and spreadsheets.
  • Google Contacts. Read-only access to the account holder's own contacts.

This is only the account holder's own Google data. The app has no access to anyone else's account, and there is no one else using it.

Why the app uses this data

Only to carry out tasks the account holder asks for. For example: filing notes, putting documents together, scheduling things on his calendar, drafting and sending mail he has asked for, and keeping records. The app does not use the data for anything else.

Where the data is kept

On the account holder's own machine, and in his own Google account. That is all.

The app has no backend service. It sends nothing to a third-party server, and there is no analytics service, no tracking and no advertising in it. Data is not copied anywhere else.

Sharing

Google user data is never sold, rented, shared, transferred or disclosed to any third party. It is not used for advertising or for profiling.

It is not used to train or improve machine learning models, and it is not used to develop any product.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

In plain terms: the app uses Google data only to do the tasks described above, it does not pass that data on, and it does not use it for advertising or to build profiles.

How long data is kept, and how to delete it

The app keeps nothing of its own. Data stays in the account holder's own Drive, mailbox or calendar for as long as he keeps it there, and he can delete any of it at any time in the normal way, through Google.

The app may hold working copies of files on his own machine while it does a task, so it does not have to download the same file twice. These copies live only on that machine and he can delete them whenever he likes.

How to stop the app's access

Go to https://myaccount.google.com/permissions and remove Hermes Agent from the list of apps with account access. Access stops immediately and the app can no longer read or change anything in the account.

Revoking access does not delete anything from Drive, Gmail or Calendar. It only ends the app's permission to reach them. After that the app holds nothing but the working copies on his own machine, and he can delete those himself.

Changes to this policy

If what the app does changes, this page changes with it. The date at the top shows when it was last updated, and this page is always the current version.
